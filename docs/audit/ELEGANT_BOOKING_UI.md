# أزرار ثلاثية الأبعاد + حجز مرحلي + إشعار صورة

الكود المصدر: [`elegant-booking-ui.php`](elegant-booking-ui.php)  
يُنشر كمقتطف Code Snippets نشط (global).

## ماذا يضيف؟

1. **أزرار منتفخة / ثلاثية الأبعاد** لكل أزرار واتساب واتصال وعرض السعر في الهيدر والهيرو والفوتر، مع شريط سفلي للجوال (واتساب + اتصال).
2. **نموذج حجز داخل المقالات** من 3 مراحل، وخياراته تتغير حسب موضوع المقال (صيانة، تنظيف، إنشاء، تسربات، …). الطلب يُحفظ في لوحة التحكم ويُرسل إلى تيليجرام.
3. **إشعار صغير بصورة** من الإعدادات، بدون أزرار واتساب/اتصال. الضغط يفتح الرابط، وعلامة × تغلقه.

## إعداد لوحة التحكم

ووردبريس → **حجوزات اليجانت**

| الحقل | الوظيفة |
|---|---|
| نظام الحجز داخل المقالات | إظهار/إخفاء النموذج |
| مفتاح بوت تيليجرام | من [@BotFather](https://t.me/BotFather) — لا يظهر للزوار |
| Chat ID | معرّف المحادثة أو القناة التي تصلك عليها الطلبات |
| إشعار الصورة | تشغيل الإعلان الصغير |
| صورة الإشعار | اختيار من مكتبة الوسائط |
| رابط عند الضغط | أي رابط (واتساب، صفحة عرض، …) |

بدون مفتاح البوت وChat ID يُحفظ الطلب في **طلبات الحجز** داخل لوحة التحكم ولا يصل تيليجرام.
