# تقرير فحص موقع Elegant Swimming Pools

**الموقع:** https://elegantswimmingpools.com  
**تاريخ الفحص:** 16 سبتمبر 2026  
**نطاق الفحص:** الواجهة العامة + لوحة ووردبريس عبر REST API بحساب المدير  
**القالب:** KAYAN Theme 1.4.2 (قالب خدمات منزلية عامة، وليس قالب مسابح مخصص)  
**ووردبريس:** 7.1 على LiteSpeed

## 1) الملخص التنفيذي

الموقع يبدو حديثًا بصريًا في الصفحة الرئيسية، لكنه **غير جاهز للتشغيل التجاري**. الهوية مختلطة بين شركة مسابح في الإمارات وقالب «خدمات منزلية» يغطي التكييف والعزل ومكافحة الحشرات، مع محتوى جغرافي لمصر والسعودية وقطر، وصفحات أساسية فارغة، وأخطاء SEO وأمان واضحة.

| المقياس | النتيجة |
|---|---|
| الجاهزية للإطلاق | منخفضة |
| الصفحات الأساسية العاملة | الرئيسية فقط بشكل شبه مكتمل |
| صفحات من نحن / اتصل بنا / الخدمات / المدونة / الأسئلة / المدن | منشورة وفارغة أو مكسورة |
| المقالات المنشورة | 1973 مقالة، 99.2% بلا صورة بارزة |
| أنواع المحتوى المخصصة (خدمات، تقييمات، أسئلة، أسعار، أعمال) | كلها صفر عناصر |
| أمان أساسي | ضعيف: مستخدم `admin` مكشوف، Wordfence متوقف، لا HSTS |

**التشخيص الجذري:** الموقع مبني على قالب KAYAN للخدمات المنزلية ثم حُقنت فيه آلاف المقالات الآلية بأسماء مدن عربية متعددة، دون ضبط هوية الشركة، ولا تعبئة الصفحات الأساسية، ولا تفعيل الصفحة الرئيسية الثابتة.

## 3) الأخطاء الحرجة (يجب معالجتها فورًا)

### C1. الصفحات الأساسية فارغة

| الصفحة | الرابط | المحتوى في ووردبريس | الوضع الظاهر |
|---|---|---|---|
| من نحن | `/about-us/` | 0 حرف | عنوان + زر مشاركة فقط |
| اتصل بنا | `/contact-us/` | 0 حرف | لا نموذج ولا هاتف ولا خريطة |
| الخدمات | `/services/` | 0 حرف | عنوان إنجليزي `services` ثم التذييل مباشرة |
| الأسئلة الشائعة | `/faq/` | 0 حرف | فارغة |
| المدن | `/cities/` | 0 حرف | فارغة |
| المدونة | `/blog/` | 513 حرفًا فقط | لا تعرض الـ 1973 مقالة |
| المتجر | `/shop/` | 0 حرف | صفحة متجر بدون WooCommerce |
| خريطة الموقع HTML | `/sitemap/` | 0 حرف | فارغة |
| Sample Page | `/sample-page/` | صفحة ووردبريس الافتراضية | يجب حذفها |

**الحل:** كتابة محتوى حقيقي لكل صفحة، أو ربطها بقوالب KAYAN الصحيحة (Services / FAQ / Contact widgets). تفعيل نموذج تواصل (WPForms مثبت ومتوقف). جعل `/blog/` هي أرشيف المقالات عبر ضبط القراءة.

### C2. الصفحة الرئيسية ليست صفحة ثابتة

إعدادات القراءة الحالية:

- `show_on_front = posts` (الموقع يعرض المقالات في الجذر)
- `page_on_front = 0`
- `page_for_posts = 170` (`/blog/`)

النتيجة:

- الصفحة الرئيسية تتصرف كأرشيف مقالات، لذلك يوجد `rel=next` إلى `/page/2/`.
- `/page/2/` يعيد **نفس عناوين H1 الخاصة بالرئيسية** (محتوى مكرر قابل للفهرسة).
- `/blog/` لا يعمل كأرشيف.
- هناك صفحة `Home` منشورة على `/0227d-home/` محتواها **قالب سفر/سياحة بالإنجليزية** (`VACATIONS ARE ALL ABOUT HAVING THE TIME OF YOUR LIFE!` / Travel experts) وليست مسابح.

**الحل:**

1. الإعدادات ← القراءة: صفحة أمامية ثابتة = صفحة رئيسية حقيقية للمسابح.
2. صفحة المقالات = `/blog/`.
3. حذف أو تحويل `/0227d-home/` إلى `noindex` ثم حذفها.
4. منع فهرسة `/page/2/` وما بعدها أو إلغاء تقسيم الرئيسية.

### C3. هوية تجارية متناقضة (مسابح مقابل خدمات منزلية)

في أعلى الرئيسية يظهر:

> «منصة **الخدمات المنزلية المتكاملة** الأولى في الإمارات»

ولوحة الخدمات تعرض: كشف تسربات، عزل أسطح، صيانة تكييف، تنظيف وتعقيم، سباكة، مكافحة حشرات.

بينما الدومين واسم الشركة «Elegant Swimming Pools / اليجانت للمسابح».

النصوص تخلط أيضًا: «الصيانة العامة»، «الأندسكيب»، «شركة EleGanT؟»، «شركة Elegant؟».

**الحل:** توحيد الهوية على المسابح فقط (إنشاء، تركيب، صيانة، تنظيف، معالجة مياه، إضاءة، شلالات، عزل حوض). إزالة خدمات التكييف/الحشرات/السباكة العامة ما لم تكن نشاطًا رسميًا معلنًا. توحيد الاسم: **Elegant / اليجانت للمسابح** بدون EleGanT أو SElegant.

### C4. أرقام تواصل متعددة ومتضاربة

| المصدر | الرقم |
|---|---|
| التذييل و`tel:` وSchema | `0521300019` (إماراتي) |
| واتساب في الواجهة | `+971521300019` |
| شعار الموقع (Tagline) في إعدادات ووردبريس | `+20 155 664 4443` (مصري) |
| Kayan DNI API `/kayan/v1/dni` | `201556644443` (مصري) |
| تذييل حقوق KAYAN WEB | `wa.me/201151481000` مع نص جاهز: «السلام عليكم - شركة كيان ويب للتسويق الإلكتروني» |

**الحل:** رقم إماراتي واحد معتمد في: التذييل، الأزرار العائمة، Schema، Rank Math، وصف الموقع، Kayan DNI، وروابط واتساب. حذف رقم مصر ورسالة «كيان ويب» من تذييل العميل.

### C5. العنوان يقول أبوظبي والخريطة تعرض دبي

- العنوان النصي: «مصفح 23، شارع 15، أبوظبي».
- الخريطة المدمجة تعرض منطقة دبي (World Islands / Jumeirah).
- Schema: `streetAddress: Abu Dhabi` ورمز بريدي `111188` (غير واقعي للإمارات).

**الحل:** إدراج إحداثيات مصفح/أبوظبي الصحيحة في Google Maps embed، وتفصيل العنوان في Schema (`Musaffah`, `Abu Dhabi`, `AE`) بدون رمز بريدي وهمي.

### C6. وسم `<title>` مفقود في كل الصفحات المفحوصة

القالب يعلن `theme_supports.title-tag = false`، والنتيجة:

- لا يوجد `<title>` في الرئيسية ولا في الصفحات الداخلية.
- لا يوجد `og:title` في الرئيسية.
- وصفان ميتا مكرران في الرئيسية (واحد من القالب: اسم الموقع فقط، وواحد من Rank Math وفيه رقم مصر).

هذا يضعف الظهور في جوجل ومشاركة روابط واتساب/تويتر بشدة.

**الحل في القالب:** إضافة `add_theme_support('title-tag');` وترك Rank Math يولّد العنوان. حذف الميتا وصف المكرر من رأس القالب.

### C7. خرائط موقع خاطئة في robots.txt

`robots.txt` يعلن 20 ملفًا `sitemap-1.xml` … `sitemap-20.xml`.  
فحص `sitemap-1.xml` يعيد **الصفحة الرئيسية HTML** وليس XML.

خريطة Rank Math الصحيحة هي `/sitemap.xml` → `sitemap_index.xml` (مقالات + صفحات + مدن).

**الحل:** الإبقاء على خريطة Rank Math فقط، وحذف السطور الوهمية من robots.txt حتى لا يزحف جوجل إلى صفحات رئيسية مكررة على أنها خرائط موقع.

### C8. صفحات 404 تُعاد توجيهها للرئيسية

الروابط غير الموجودة تعيد 200 على الرئيسية (soft 404). هذا يضر الفهرسة ويخفي الأخطاء.

**الحل:** صفحة 404 حقيقية برمز 404، مع بحث داخلي وأزرار واتساب/خدمات.

## 4) أخطاء المحتوى والجغرافيا

### 4.1 محتوى جماعي منخفض الجودة

- **1973 مقالة** منشورة.
- **1957 بلا صورة بارزة (99.2%)**.
- **106 عناوين مكررة**.
- أنماط عناوين آلية: «شركة مقاول إنشاء…»، «شركة تنظيف حمامات…»، «شركة تصميم شلالات…» عشرات المرات مع تغيير اسم المدينة فقط.
- وسوم slug إنجليزية من نشاط آخر: `decoration-company-in-mansoura`، `gypsum-board-parquet-painting-mansoura`.
- تصنيف المدن: أبوظبي **مقالة واحدة** مقابل المنصورة 30، الرياض 28، 6 أكتوبر 28، الطائف 29… أي أن السوق الإماراتي ليس مركز المحتوى.

### 4.2 تعارض التقييمات والأرقام

| المكان | الادعاء |
|---|---|
| شريط الرئيسية | 4.9/5 و 1,247+ تقييم Google و 15,000+ عميل |
| بطاقة الـ Hero | +15,000 عميل و +30,000 خدمة و 4.9 |
| Schema AggregateRating | 5.0 من 2541 مراجعة |
| ودجات المقالات | توزيع نجوم عشوائي الشكل |

أرقام غير متسقة وغير موثّقة. جوجل قد تعتبر التقييمات المنظمة مزيّفة إذا لم تطابق مصدرًا حقيقيًا.

**الحل:** رقم واحد حقيقي من ملف الشركة التجاري/جوجل بزنس فقط. إزالة Schema التقييم إن لم يكن من مراجعات فعلية على الموقع (`review` CPT فارغ حاليًا: 0).

### 4.3 أعمال سابقة بدون صور

قسم «سابقة أعمال» يعرض أيقونات حقيبة بدل صور مشاريع، والروابط تعود للرئيسية (`/?p=306`). أنواع `portfolio` و`before_after` فارغة.

**الحل:** رفع 9–15 صورة مشاريع حقيقية (قبل/بعد) في CPT Portfolio مع مدينة ونوع الخدمة.

### 4.4 أسعار بدون أسعار

بطاقات AED بعنوان «أسعار تنظيف/صيانة/إنشاء المسابح» ثم رابط «اقرأ الدليل» دون رقم. CPT `pricing` = 0.

**الحل:** إما جداول أسعار تقريبية بالدرهم مع «السعر بعد المعاينة»، أو تحويل القسم إلى «اطلب عرض سعر» دون إيهام وجود تسعيرة.

### 4.5 الأسئلة الشائعة في الرئيسية بلا عناصر

عنوان القسم موجود، وCPT `faqs` = 0. صفحة `/faq/` فارغة.

### 4.6 تداخل نص في المقالات

في `/decoration-company-in-mansoura/` عنوان المقالة يتداخل بصريًا مع اسم الموقع (watermark). تصنيف المقال يظهر `categories` بدل اسم تصنيف عربي. هذا خطأ CSS/قالب + تصنيف غير مسمى.

## 5) أخطاء التجربة وواجهة الاستخدام

1. **قائمة الهامبرغر** لا تعرض روابط الصفحات؛ تظهر أزرار واتساب/اتصال فقط. القوائم موجودة في ووردبريس (Header/Footer) لكن القالب لا يرسمها في الموبايل.
2. **الشعار شبه مختفٍ** في الصفحات الداخلية (شعار فاتح على هيدر أبيض).
3. **لا نموذج تواصل** في أي صفحة (0 نماذج HTML في الرئيسية).
4. **لا مبدّل لغة** رغم خلط عربي/إنجليزي (Polylang مثبت ومتوقف).
5. **عنوان صفحة الخدمات بالإنجليزية** (`services`) مع نص «جميع مقالات services».
6. **أزرار عائمة** جيدة الفكرة، لكن أحد روابط واتساب في التذييل يفتح رقم وكالة التصميم لا رقم العميل.
7. **WooCommerce بقايا:** سلة، إتمام طلب، حسابي، سياسة استرداد — بدون إضافة المتجر. تربك الزائر ويجب حذفها أو إكمال المتجر إن كان بيع مواد كيميائية للمسابح مقصودًا.

## 9) الحلول المقترحة حسب الأولوية

### الأسبوع الأول — إصلاح الثقة والتحويل

1. توحيد رقم واتساب/هاتف الإمارات في كل المصادر وإزالة أرقام مصر وكيان ويب.
2. إصلاح خريطة جوجل على مصفح أبوظبي.
3. ملء صفحات: من نحن، اتصل بنا (نموذج + خريطة + أوقات العمل)، الخدمات (6 خدمات مسابح فقط).
4. إصلاح القائمة الرئيسية والهامبرغر: الرئيسية، الخدمات، أعمالنا، من نحن، المدونة، اتصل بنا.
5. ضبط القراءة: صفحة أمامية ثابتة + أرشيف المدونة.
6. تفعيل `title-tag` وإعادة توليد عناوين Rank Math.
7. حذف `/sample-page/` و`/0227d-home/` وصفحات السلة/الحساب إن لم يكن هناك متجر.
8. robots.txt: خريطة Rank Math فقط. صفحة 404 حقيقية.

### الأسبوع الثاني — الهوية البصرية والدليل الاجتماعي

9. شعار داكن للهيدر الفاتح. توحيد الاسم.
10. استبدال لوحة خدمات التكييف/الحشرات بخدمات المسابح.
11. رفع صور مشاريع حقيقية وإيقاف أيقونات الحقيبة.
12. 8–10 أسئلة شائعة حقيقية عن المسابح في الإمارات (مياه، طحالب، تسريب، شتاء، ضمان).
13. توحيد أرقام العملاء/التقييمات مع جوجل بزنس أو حذف الادعاءات غير الموثقة من Schema.
14. تفعيل Wordfence + إخفاء المستخدمين من REST + تغيير اسم المدير.

### الأسبوع الثالث — المحتوى والفهرسة

15. جرد الـ 1973 مقالة: الإبقاء على صفحات الإمارات عالية الجودة فقط، و`noindex` أو دمج/حذف صفحات مصر/السعودية/قطر إن كانت الشركة لا تخدمها فعليًا.
16. صور بارزة لكل صفحة خدمة/مدينة متبقية.
17. إصلاح تصنيف `categories` الظاهر في فتات الخبز.
18. تفعيل GA4.
19. ربط Google Search Console وإرسال الخريطة الصحيحة واستبعاد soft 404.
20. إن كانت الحجز مطلوبًا: ضبط Amelia لخدمة «معاينة مسابح» أو إزالة الإضافة.

## 10) مقترحات تطوير (بعد الإصلاح)

- معرض قبل/بعد مع Photoswipe (مكتبة القالب محملة أصلًا).
- آلة حاسبة تقديرية لمساحة المسبح → تحويل لواتساب.
- صفحات إمارات حقيقية: أبوظبي، دبي، الشارقة، العين… بمحتوى محلي وعناوين NAP متطابقة.
- شهادات بلدية دبي/أبوظبي كملفات قابلة للتحقق لا شارات نصية فقط.
- نسخة إنجليزية منفصلة عبر Polylang إذا كان الجمهور مختلطًا، لا خلط الجمل داخل الصفحة.
- سياسة خصوصية عربية (الحالية إنجليزية افتراضية من ووردبريس) وملف Cookies.
- بيانات LocalBusiness كاملة: `geo`, `areaServed`, `sameAs` لحسابات التواصل، و`openingHoursSpecification` بدل القيمة غير الصالحة `"24"`.

## 12) الخلاصة

الموقع يحتاج **تصحيح هوية** قبل أي حملة إعلانية أو SEO إضافي. الاستمرار في نشر مئات المقالات الآلية مع صفحات «من نحن» و«اتصل بنا» فارغة، ورقم مصري في الوسم، وخريطة دبي لعنوان أبوظبي، سيزيد الضرر على العلامة وثقة جوجل.

**ترتيب التنفيذ الموصى به:** توحيد التواصل والجغرافيا ← ملء الصفحات الأساسية والقائمة ← ضبط الرئيسية الثابتة والعنوان SEO ← تنظيف المقالات والإضافات والأمان.
